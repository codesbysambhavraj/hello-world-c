# Hello World in C

A simple Hello World program written in C. This is my first repository, created to practice C programming and the Git/GitHub workflow.

## Requirements
- A C compiler such as GCC

## How to run
```bash
gcc hello.c -o hello
./hello
```

## Output
```
Hello, World!
```

## What I learned
- Structure of a basic C program (`#include`, `main`, `printf`)
- Compiling C code with GCC
- Using Git to add, commit, and push code
